# GNSS - Support Components & Critical Notes

## Why SAM-M10Q?
Since the main purpose is to design a GNSS+Compass module for unmanned vehicles as a first project, the design making is driven by simplisity and low cost, yet while constrained by using components that's supported by the most common open source autopilots (ArduPilot & PX4).
The U-blox SAM-M10Q chip meets those requirements, it only cost ~13 USD, and has an intergrated antenna in the same chip that reduce the board design complexity. And since most autopilots support UBX used by U-blox chips, it meets the compatibility creteria.
